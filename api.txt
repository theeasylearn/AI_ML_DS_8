What is Client?
-----------------------------------------------------------------------------------------
Client can be any device(computer/tablet/pc) that can send request to other computer for information. Client receive response of request from server. Client computer must be connected with server computer using any communication channel. Client computer always send request on specific address known as URL (Universal Resource Locator / Uniform resource Locator). in simple mostly it kind of web page. after client receive response of request, client and server gets disconnect 

What is Server?
------------------------------------------------------------------------------------------
Server accept request send by client computer Process it generate & return response of back to client computer. Server computer use a particular technology/platform to process the request. this can be 

Python
PHP
asp.net
node js or can be anything 

to process request in python we need to use particular framework/library. for example one can use

Django 
Flesk 
fastAPI for this purpose 

what is A.P.I?
-----------------------------------------------------------------------------------------
    full form of API is application programming interface. A.P.I is used to connect two different application & share data between them. to share data application use JSON format. main job of api is to 
        1) accept request from client
        2) process (activate model and supply input to it, receive output)
        3) return output as response to client
